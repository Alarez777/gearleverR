# Translations

- `upstream/` contains the catalogs of the original Gear Lever (GPL-3.0-or-later).
- `overrides/` contains translations for strings that only exist in Gear LeverR
  (currently Spanish). They win over the upstream catalog.
- `<lang>.po` files are generated by `scripts/update-translations.sh`:
  `upstream/<lang>.po` + `gearlever-r.pot` + `overrides/<lang>.po`.
- `gearlever-r.pot` is generated from `t("...")`/`tf("...")` calls. Do not edit it.
- `scripts/compile-translations.sh [prefix]` writes
  `<prefix>/locale/<lang>/LC_MESSAGES/gearlever-r.mo`.

To improve a language, edit `overrides/<lang>.po` for the new strings (or send a
patch against the generated `<lang>.po`), then rerun the update and compile
scripts. Strings without a translation fall back to English.
