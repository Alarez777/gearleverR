# Translations

- `upstream/` contains the catalogs of the original Gear Lever (GPL-3.0-or-later).
- `overrides/` contains Gear LeverR-specific strings and corrections to upstream
  wording. Every language has one, and its entries win over the upstream catalog.
- `<lang>.po` files are generated by `scripts/update-translations.sh`:
  `upstream/<lang>.po` + `gearlever-r.pot` + `overrides/<lang>.po`.
- `gearlever-r.pot` is generated from `t("...")`/`tf("...")` calls. Do not edit it.
- `scripts/compile-translations.sh [prefix]` writes
  `<prefix>/locale/<lang>/LC_MESSAGES/gearlever-r.mo`.

To improve a language, edit `overrides/<lang>.po` (or send a patch against the
generated `<lang>.po`), then rerun the update and compile scripts. Strings
without a translation fall back to English.

## Install/open terminology

The `msgid` values stay in English and match upstream so their translations can
be reused. The visible label may be shorter: for example, `Move to the app menu`
is translated as `Instalar` in Spanish and `Installer` in French. Only the
translation changes, not the key.

`overrides/` keeps the everyday actions aligned across languages:

- launching an AppImage is "Open"/"Abrir", not "Launch"/"Lanzar";
- integrating it into the app menu is "Install"/"Instalar", not "Move"/"Mover";
- the states and messages say "installed"/"instalada", not "integrated".

The file-management setting `Move AppImages into the destination folder` is a
real file move and keeps its own wording; it is unrelated to installation.
